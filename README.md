# React Todo App — ETP Demo

A simple ReactJS Todo app demonstrating:
- useState
- event handling
- conditional rendering
- array.map()
- keys
- filter()
- dynamic UI updates

## Run it

1. Open this folder in VS Code.
2. Open the terminal.
3. Run:

   npm install

4. Then:

   npm run dev

5. Open the localhost URL shown by Vite.

## ETP demo flow

1. Start with an empty list — show the conditional empty state.
2. Add a task — state changes.
3. Add multiple tasks — map() renders the list.
4. Point out `key={task.id}`.
5. Complete a task — state updates.
6. Delete all tasks — empty-state conditional rendering appears again.
